# Commercial launch checklist

## Must complete before general paid sale
- [ ] Decide and document the legal trading entity/name.
- [ ] Complete provider address and company/trader details in contracts and website.
- [ ] Confirm VAT/tax/accounting treatment.
- [ ] Obtain appropriate professional/cyber/public liability insurance advice.
- [ ] Legal review of Terms of Service and DPA.
- [ ] Verify privacy notice against actual production suppliers and data flows.
- [ ] Verify and publish subprocessor register.
- [ ] Run cross-tenant security tests for every customer-data module.
- [ ] Move high-volume evidence files from PostgreSQL/base64 to private object storage.
- [ ] Implement storage/usage monitoring and alerts.
- [ ] Define customer onboarding/offboarding process.
- [ ] Define support channel and severity handling.
- [ ] Complete a backup restore test and set internal RPO/RTO targets.
- [ ] Document incident contact/escalation.
- [ ] Confirm production MFA and least-privilege access for hosting accounts.
- [ ] Add automated dependency/secret scanning to CI.
- [ ] Define plan limits in code/config before enforcing commercial subscriptions.
- [ ] Add billing/subscription handling before self-service purchase is enabled.
