# Infinit Audit commercial readiness pack

Status: **working commercial drafts — review before first external paid customer**.

This folder records the operational, privacy, security and contractual controls needed to take Infinit Audit from an internal/pilot system to a multi-customer SaaS product.

Documents:
- `security-model.md` — architecture, access control, tenant isolation and security expectations.
- `data-retention-deletion.md` — retention, deletion and offboarding rules.
- `backup-restore.md` — backup ownership, restore expectations and testing.
- `incident-response.md` — security/data incident process.
- `subprocessors.md` — supplier register and due-diligence checklist.
- `data-processing-agreement.md` — UK GDPR processor terms template.
- `terms-of-service.md` — commercial SaaS terms template.
- `photo-storage.md` — image compression, storage limits and migration plan.
- `commercial-launch-checklist.md` — items that must be completed before general sale.

These documents are operational templates, not legal advice. Provider legal identity, registered/business address, VAT position, governing-law details, insurance and final supplier details must be completed and professionally reviewed before general commercial launch.
